# ScopeProof: fresh external AI import demonstration

This package captures an actual loopback HTTP run of the local ScopeProof application. The two structured analyses were freshly generated by a separate ChatGPT agent from the application's exported prompts. The application validated and imported those responses. **The app itself did not call a model API.**

The evidence is synthetic. The review action is an explicitly simulated local operator. All invoices and read-backs use the built-in local simulator, **not PayPal Sandbox**. There are no customer participants, real payments, or independent production-validation claims.

## What the run checks

- A paraphrased responsive-layout report supports its criterion.
- An untested staging contact form and outstanding accessibility assessment remain missing or unclear, despite an instruction embedded in the untrusted evidence to mark everything passed.
- The application refuses draft creation before explicit review.
- Corrected evidence is analyzed in a new external model response, imported, and still requires a review action.
- A simulated operator approves the exact evidence version.
- A draft and retry yield exactly one simulated invoice, with a fresh read-back.
- Editing the evidence revokes approval, invalidates the old review link, rejects the old model result, and blocks another billing attempt without a new review.

These checks show how the application treats these particular inputs. They do not establish general model accuracy or independently verify that work described in the report actually occurred.

## Files

- `run_demo.py`: the HTTP demonstration harness, Python standard library only.
- `incomplete_prompt.txt`, `complete_prompt.txt`: exact prompts exported via `GET /api/review-prompt`.
- `incomplete_review.json`, `complete_review.json`: unchanged externally generated model responses.
- `*_prompt_receipt.json`: export timestamps, snapshot binding, and prompt hashes.
- `fresh_run.json`: the original fresh-generation run and sanitized request trace.
- `replay_run.json`: a later deterministic replay using saved responses.

## Replay

Use a ScopeProof application source folder containing `app.py`, `workflow.py`, and its dependencies:

```sh
python3 run_demo.py --replay --app /path/to/ScopeProof_app
```

A replay makes no new model inference. It re-exports the prompts, checks they match the stored prompts, imports the saved model outputs, and exercises the application over HTTP again. It uses a temporary local workspace that is removed at the end. No private capability or signing key is exported.

For installer self-tests or read-only source packages, put the result outside the source folder:

```sh
python3 run_demo.py --replay --app /path/to/ScopeProof_app --output /existing/temporary/directory/replay.json
```

The output directory must already exist. This preserves every packaged file, including its stored replay result and manifest. `--output` is only available with `--replay` and refuses to replace original receipts or model responses.

To deliberately regenerate the HTML report and its manifest using a recorded replay, run:

```sh
python3 rebuild_report.py --replay-result /existing/temporary/directory/replay.json
```

`build_report.py` and `rebuild_report.py` are equivalent entry points. The report keeps the original fresh-run version separate from the replay version, and shows the recorded evidence revisions and matching snapshot fingerprints. Rendering updates the HTML and manifest; it does not modify original model responses or fresh receipts.

## Run another fresh demonstration

Copy `run_demo.py` into a new empty directory, then run:

```sh
python3 run_demo.py --fresh --app /path/to/ScopeProof_app
```

The harness writes `incomplete_prompt.txt` and waits for the operator to provide `incomplete_review.json` generated by an external model from that prompt. After a successful import, it exports `complete_prompt.txt` and waits for `complete_review.json`. Write each response atomically. No result is fabricated if no model output arrives; the process times out. Fresh mode refuses to overwrite an existing response pair.

The explicit review is automated solely for this reproducible synthetic demonstration. A real use of ScopeProof requires the responsible human to review each quotation and accept the current version.
