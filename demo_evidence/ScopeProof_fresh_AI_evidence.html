  3. A simulated local operator accepted each criterion for the current snapshot.
  4. Two draft attempts produced exactly one simulator invoice, INV2-MOCK-0001, with a verified read-back.
  5. Editing the evidence revoked approval and cleared the imported analysis.
  6. The previous model response returned AI_REVIEW_STALE; the old review link was refused; another billing attempt required a new review.
What this proves — and its limits

This is a reproducible functional check of this synthetic case. The app did not call a model API: a separate ChatGPT agent generated responses to exported prompts. The app correctly labels the import IMPORTED_REVIEW_UNVERIFIED_AUTHOR. Approval was an explicit simulated operator action, not a customer identity check. Billing was the local simulator, not PayPal Sandbox. This is not an independent audit, a model accuracy estimate, or proof that the reported delivery happened.
